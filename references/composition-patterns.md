# Composition Patterns & Originality Rules

## Basic Structure Types

Choose only one structure type per image to keep the message crystal clear:

### 1. Workflow (Data & AI Pipelines)
- **Use for**: R&D experiments -> Model Training -> API Deployment -> Enterprise SaaS.
- **Composition**: Input on the left, Capynacci operating a central processing node in the middle, output on the right with orange flow arrows.

### 2. System Partial (Architecture Focus)
- **Use for**: Inspecting specific AI system modules (e.g., Vector DB, RAG Retriever, LLM Engine, GPU Memory).
- **Composition**: Draw 3-5 core modules, with Capynacci tuning weights or connecting wires on the key module.

### 3. Before and After Comparison (Optimization / Transformation)
- **Use for**: Manual workflow vs Automated AI system, High Loss vs Low Loss, Fragmented Data vs Structured Pipeline.
- **Composition**: Chaos/inefficiency on the left, streamlined system on the right, orange transition arrow in the middle.

### 4. Character State (Researcher / Founder Perspective)
- **Use for**: Developer pain points, system bottlenecks, handling CUDA OOM, balancing R&D with business goals.
- **Composition**: Capynacci calmly dealing with a chaotic server stack or complex research paper equation.

### 5. Conceptual Metaphor (Abstract to Physical)
- **Use for**: Explaining complex algorithms, reinforcement learning loops, embedding space projections.
- **Composition**: Physical representation (e.g. Capynacci using a physical sorting scale or dial machine to project high-dimensional data).

### 6. Method Layering (Tech Stack & Architecture Layers)
- **Use for**: Infrastructure stack (Hardware -> Linux/Docker -> Model Layer -> SaaS API).
- **Composition**: Stacked hand-drawn layers with Capynacci placing the top product block.

### 7. Map Route (Research to Commercialization Path)
- **Use for**: Product roadmaps, R&D milestones, grant-to-patent journeys.
- **Composition**: Winding hand-drawn path with key milestone nodes; Capynacci walking or guiding the path.

### 8. Comic Panels (Process Storytelling)
- **Use for**: Short 2-4 panel narratives explaining a problem and its technical solution.

## Metaphor Generation Method

1. **Turn Abstract to Physical**: Turn "weights optimization" into turning physical dials; turn "data ingestion" into feeding data streams into a funnel engine.
2. **Use Tech & Lab Objects**: GPU racks, physical weight dials, R&D clipboards, container boxes, pipeline funnels, smart tablets, node connection wires.
3. **Capynacci's Action**: Capynacci must be actively pulling, turning, connecting, inspecting, or guiding the system component, remaining completely calm and unbothered.
